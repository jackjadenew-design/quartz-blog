# 🎭 Multi-Expert Debate Skill：让AI帮你做真正的深度辩论分析

让AI进行对话，应改早就有很多人做过了。今天我用腾讯的WorkBuddy生成了一个skill。这个skill可以根据议题产生十几个不同的角色，让这些角色进行辩论，最后对辩论结果进行总结。挺有意思的，只是很耗费token。

以下是AI对这个skill的总结：

> 一个工具，召集10-14位专家，进行4轮互联网驱动的结构化辩论，输出8000+字的分析报告和学术论文。

---

## 是什么？

**Multi-Expert Debate Skill** 是 WorkBuddy 的一个专业扩展技能，核心理念是：

> 把一个复杂问题，变成一场**真正有张力的跨学科辩论**，而不是 AI 的自说自话。

它的方法论叫做 **Tension-Driven Convergence（张力驱动收敛）**：
- 专家们持有**真实的、对立的**立场，不打太极
- 真实的分歧被**如实记录**，而不是被粉饰
- 共识必须通过**真正的论辩**来赢得
- 每位专家发言前，**必须先搜索互联网最新资料**

## 核心特性（v3.0）

| 特性 | 说明 |
|------|------|
| 🤖 **全自动执行** | 无需用户反复确认，一次触发，全程自动运行到底 |
| 🌐 **互联网优先** | 每一轮，每位专家必须先搜索，论点必须有当下数据支撑 |
| 👥 **强制普通人视角** | 必须包含至少1位普通市民，从亲身经历出发发言 |
| ⚔️ **至少3对对立专家** | 确保辩论有真正的火花，不是"大家都有道理" |
| 📄 **双输出：报告 + 论文** | Phase 4生成结构化分析报告，Phase 5生成去AI味的学术论文 |
| 🛡️ **质量控制 v2.0** | 分段生成机制，解决后期发言文字减少、质量下降问题 |

## 执行流程

```
Phase 0：议题分析 + 全面网络调研
    ↓
Phase 1：智能角色阵容生成（10-14人）
    ↓
Phase 1.5：确认原始记录保存路径
    ↓
Phase 2：互联网驱动的结构化辩论（4轮）
    ↓
Phase 3：立场收敛测试
    ↓
Phase 4：生成结构化分析报告（8000-12000字）
    ↓
Phase 5：生成真人风格学术论文（3000-6000字）
```

---

## 角色阵容构成规则

Skill 会**自动分析议题维度**，动态生成专家阵容。强制规则如下：

- **至少3对对立专家**（保证真实冲突）
- **至少5个不同学科**（保证跨领域视野）
- **恰好1位主持人**（不参与辩论，负责提炼张力图）
- **恰好1位魔鬼代言人**（质疑所有人的论点）
- **至少1位普通市民**（从生活经验出发，这是强制要求）
- **至少1位切线视角专家**（来自不相关领域，提供意外洞见）

## 4轮辩论结构

| 轮次 | 任务 | 最低字数 | 最低数据点 |
|------|------|----------|----------|
| **Round 0（事实核查）** | 确认/质疑事实底稿 | 200字 | 1个 |
| **Round 1（立场亮明）** | 阐述核心论点 | 300字 | 1个 |
| **Round 2（第一轮交锋）** | 直接攻击对方论点 | 350字 | 2个 |
| **Round 3（深化争论）** | 提供更多证据，加深分歧或推进 | 350字 | 2个 |
| **Round 4（综合更新）** | 明确立场是否改变及原因 | 300字 | 1个 |

> **质量控制**：每轮结束后自动检查字数和数据密度，不达标则强制补充发言。

---

## 两种输出

### 📊 Phase 4：结构化分析报告
- 执行摘要（结论优先，500字）
- 共识地图（大家同意什么）
- 张力地图（分歧在哪，为何无法解决）
- **立场转变分析**（哪些论点改变了谁的观点——这是最有价值的部分）
- 普通市民视角专节
- 调研质量评估
- 未解决问题清单
- 完整引用索引

### 📝 Phase 5：真人风格学术论文
专门避免AI腔的写作风格：
- ❌ 禁用："首先、其次、综上所述、值得注意的是"
- ✅ 提倡：自然段落过渡、"笔者认为"、直接引用专家话语、短句增加节奏感

## 如何触发

直接在 WorkBuddy 中输入：

```
@skill://multi-expert-debate  [你的议题]
```

示例：
```
@skill://multi-expert-debate  AI浪潮下，大学教育还有价值吗？
```

```
@skill://multi-expert-debate  碳中和目标与经济增长真的能兼容吗？
```

系统会自动进入Phase 0，开始全程执行。

> ⚠️ **注意**：触发后会询问原始记录的保存路径（Phase 1.5），建议提前准备好Obsidian或本地路径。

## 技术亮点：质量控制 v2.0

传统连续生成的问题：

> Round 1发言平均350字 → Round 4降至180字（-49%）

**解决方案：分段生成机制**

每轮辩论**独立生成**，只传递500字的"智能摘要"到下一轮，而不是全部历史内容。效果：

| 指标 | 改进前 | 改进后 |
|------|--------|--------|
| 后期平均字数 | 180字 | 350字 |
| 每轮数据点数量 | 12-15个 | 24-30个 |
| 魔鬼代言人锐度 | 6-7/10 | 8-9/10 |
| 论证深度 | 6.5/10 | 8.5/10 |

## 适合什么场景？

✅ **复杂政策问题分析**（碳税、全民基本收入、教育改革）  
✅ **技术伦理议题**（AI监管、基因编辑、隐私 vs 安全）  
✅ **经济与社会争议**（全球化利弊、房价调控、劳动力市场）  
✅ **哲学与价值观冲突**（自由 vs 平等、短期利益 vs 长期可持续）  
✅ **需要多视角的研究准备**（写论文前的观点摸底）  

❌ **不适合**：事实查询类问题、单一领域的技术问题、答案已明确的问题

---

## 小结

Multi-Expert Debate Skill 的价值不在于给你一个**答案**，而在于帮你看清楚：

1. 这个问题**有哪些真实的分歧维度**
2. **哪些论点真正有说服力**（能改变其他专家的论点）
3. **普通人的视角**在精英辩论中往往被忽视的那些东西
4. **目前互联网上最新的数据和观点**是什么

> 与其让AI给你一个"全面客观的总结"，不如让它组织一场真正的多方交锋。
